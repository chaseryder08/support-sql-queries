# Support SQL Queries

A small practice database built around the kind of questions a technical support engineer gets asked every day.

It includes a simple set of tables (users, jobs, sync events, and errors), some fake sample data, and about a dozen SQL queries. Each query has a short comment explaining the support question it answers, like "Which jobs failed to sync in the last 24 hours?" or "Which users were set up but never logged in?"

Built with SQLite.
